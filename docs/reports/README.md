# Bằng chứng và báo cáo đồ án

Nơi chuẩn bị báo cáo cuối: [BAO_CAO_DO_AN.md](BAO_CAO_DO_AN.md). Báo tiến độ hằng buổi/vướng mắc/nghiệm thu ở [quy trình nhóm](../team/BAO_CAO.md), không tạo tám file nhật ký độc lập xung đột cùng một thông tin.

Khi có dữ liệu thật, đưa bằng chứng **được phép và đã ẩn danh** vào PR của task, hoặc link artifact/ảnh/log GitHub phù hợp. Tên gợi ý `ngay-task-loai-bang-chung`; ghi commit, môi trường, lệnh chạy, kỳ vọng/thực tế, người thực hiện/review, fixture hay model thật. Không commit file tải xuống của giáo viên, bản ghi âm phỏng vấn, secret, DB thật hay model weights.

| Loại bằng chứng | Ghi tối thiểu |
|---|---|
| Phỏng vấn/quan sát | Mã người, vai trò liên quan, ngày, đồng ý sử dụng, câu hỏi/quan sát, điều chưa biết |
| Baseline | Công cụ/phiên bản/ngày, tác vụ giống nhau, kết quả, ảnh được phép |
| Test kỹ thuật | Commit, command, input fixture, expected/actual, pass/fail, giới hạn |
| PoC model | Dataset mẫu được phép, model/params/provenance, số ca đúng/sai, chi phí/thời gian thực đo |
| Usability/accessibility | Tác vụ, cỡ mẫu, thời gian/lỗi/trợ giúp, ảnh đã ẩn danh, vấn đề và kiểm lại |
| Nghiệm thu | Issue/PR, acceptance có link từng bằng chứng, reviewer, kết luận và điều chưa kiểm |

Đã có [proposal, Decomposition và Abstraction của nhóm](../course/HO_SO_DA_CO.md), cùng nhật ký cải tiến tài liệu. Tận dụng các đầu ra đó; các bảng trống chỉ dành phần còn thiếu. Trong hồ sơ đã đọc chưa thấy đủ ghi chép ba người dùng, kết quả PoC mới hoặc benchmark sản phẩm; không đồng nhất việc rà slide với nghiệm thu app.
